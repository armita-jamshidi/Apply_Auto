# Specs

One file per roadmap item, numbered in the order they were written:
`NNN-short-name.md`. Write the spec before the code, and update it in the same PR as the
change.

Each spec has: Status, Problem, Expected behavior, and How to test. Add "Suspected causes"
for bugs. Use fictional examples only; never paste real postings with the candidate's
answers, or anything from `profile/`.
