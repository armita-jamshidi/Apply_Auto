# Customers

The product has one customer: the candidate who runs it. They are the buyer and the user.

Their pains, in order:

1. Tailoring the resume to each job description takes too long.
2. Preparing answers for each application's questions takes too long.
3. Finding roles that fit (remote, or in the Research Triangle area) is slow.

Personal details about the candidate go in `customers/candidate.md`, copied from
[candidate.example.md](candidate.example.md). Everything in this folder except this README
and the template is git-ignored and blocked by the privacy hook.
