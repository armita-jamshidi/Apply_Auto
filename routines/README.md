# Routines

Prompts for work that runs on a schedule. Each file is the full prompt a scheduled Claude
Code session receives, so it must stand on its own.

| Routine | Schedule | What it does |
| --- | --- | --- |
| [daily-roadmap.md](daily-roadmap.md) | Daily | Takes the next roadmap item one step forward and opens or updates a PR. |

Routines never merge, never push to `main`, and never touch personal data.
